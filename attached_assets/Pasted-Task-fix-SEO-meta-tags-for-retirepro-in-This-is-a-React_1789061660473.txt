--- CHANGE 1: canonical URLs must use trailing slashes ---
The server 301-redirects /blog/foo to /blog/foo/ (with slash), but the
client-side canonical tag currently outputs the NO-slash version. That is a
redirect loop from Google's point of view.
Find where the canonical <link> is set at runtime (React Helmet, react-helmet-async,
a useEffect, or a custom SEO component) and make it always output a trailing slash,
e.g. https://retirepro.in/blog/why-indians-fail-retirement/
Homepage stays https://retirepro.in/

--- CHANGE 2: sitemap.xml must use trailing slashes ---
Open public/sitemap.xml (or wherever sitemap.xml lives). Add a trailing slash to
every single <loc> except the homepage. Example:
  before: <loc>https://retirepro.in/blog/nps-vs-ppf-vs-sip</loc>
  after:  <loc>https://retirepro.in/blog/nps-vs-ppf-vs-sip/</loc>
Do not add, remove or reorder any URLs. There are 22.

--- CHANGE 3: build-time prerender of meta tags (the important one) ---

description appear after JavaScript runs. FIND that existing data source (a routes

REUSE it. Do not invent new titles or descriptions.

Then add a post-build Node script, scripts/prerender-meta.mjs, that runs AFTER

Wire it into package.json so it runs automatically, e.g.
